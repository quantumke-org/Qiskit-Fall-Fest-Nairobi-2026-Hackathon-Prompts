# ⚛️ Qiskit Fall Fest Nairobi 2026 Hackathon

Welcome to the **Qiskit Fall Fest Nairobi 2026 Hackathon**!

This is a beginner-friendly, individual challenge designed for anyone interested in exploring **quantum computing with Qiskit**. No prior quantum experience is required.

> **Learn → Experiment → Build → Submit → Win 🏆**

## 🤖 AI Policy

**AI tools are allowed and encouraged.**

You may use ChatGPT, Claude, Gemini, GitHub Copilot, or other AI tools to:

* Learn quantum concepts
* Understand Qiskit
* Generate and debug code
* Explore solutions
* Get hints

However, you are responsible for **understanding and testing your submission**.

If AI significantly contributed to your solution, briefly disclose how you used it.

See the full [AI Usage Policy](AI_POLICY.md).
